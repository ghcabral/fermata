# Fermata

Editor de partituras musicais para web e desktop.

- **Usar no navegador:** https://ghcabral.github.io/fermata/
- **Baixar para Windows:** [Fermata-Setup.exe](https://github.com/ghcabral/fermata/releases/latest/download/Fermata-Setup.exe)

O instalador ainda não tem assinatura digital. Se o Windows mostrar
“O Windows protegeu o computador”, clique em **Mais informações** e depois em
**Executar assim mesmo**.

Este repositório só distribui as versões publicadas; o código-fonte é fechado.
